# Gesture Pong — Browser Edition

## Menjalankan game
1. Ekstrak ZIP.
2. Buka folder `GesturePong_Web` di VS Code.
3. Jika punya extension **Live Server**, klik kanan `index.html` → **Open with Live Server**.
4. Alternatif: buka terminal di folder proyek dan jalankan `py -m http.server 8000`, lalu buka `http://localhost:8000`.
5. Klik Start Game dan izinkan kamera. Pastikan internet aktif untuk memuat MediaPipe.

## Kontrol
- Pemain 1: telunjuk di sisi kiri gambar webcam atau tombol W/S.
- Pemain 2: telunjuk di sisi kanan gambar webcam atau tombol panah atas/bawah.
- Space: mulai/jeda.
- R: mulai ulang.

Kamera memerlukan localhost atau HTTPS dan izin browser. Untuk dibagikan secara online, unggah folder ini ke hosting statis seperti GitHub Pages atau Netlify.
